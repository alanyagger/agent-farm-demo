# 五分钟演示讲稿

## 0:00 - 0:40 产品背景

“这个 Demo 解决三个问题：智能体是谁、它有没有资格执行、执行后如何追溯。页面里预置了三位主人和三个智能体，每个主人都有实名 DID，每个智能体则需要自己的 AIC 和身份 VC。”

## 0:40 - 1:30 有效凭证智能体自动运行

1. 选择主人“林晓”，展示智能体“青芽”的“凭证有效”状态。
2. 指出 AIC、最近执行时间和农场资产。
3. 点击“运行一次”，观察智能体按顺序完成收获、补种或邻居采摘。
4. 切换到“行为记录”，展示动作原因、目标、凭证校验结果和 `traceId`。

讲解词：“游戏引擎不直接相信智能体自己声明的身份。每次行动前都会经过凭证 Provider，只有 ACTIVE 状态才会进入规则引擎。”

## 1:30 - 2:20 无凭证准入拦截

1. 切换主人“陈屿”，此时“田小诺”显示未申领。
2. 在“我的农场”点击“运行一次”。
3. 切到“行为记录”，筛选“准入拦截”。

讲解词：“没有身份凭证时，种植、收获和邻居采摘都不会执行，但拒绝结果本身会留下审计记录，能够看到失败原因和追踪号。”

## 2:20 - 3:20 完整申领与签发

1. 进入“智能体身份”。
2. 点击“申领智能体身份凭证”。
3. 展示四步轨迹：主人实名 DID、创建 AIC、提交凭证申领、VC 生效。
4. 回到农场再次点击“运行一次”，确认动作成功。

讲解词：“这里没有直接修改状态，而是通过统一 Provider 完成创建和签发。以后接真实环境，只需要替换 Provider，不影响游戏。”

## 3:20 - 4:10 社交行为与主人可见

1. 查看“邻居农场”，指出成熟作物和邻居智能体凭证状态。
2. 运行有效智能体，等待一条邻居采摘记录。
3. 切换到被影响的主人，在行为记录中选择“影响我的农场”。

讲解词：“主人能看到自己的智能体做过什么，被影响的农场也能看到是谁、在什么时间、凭什么身份执行了动作。”

## 4:10 - 5:00 吊销后立即失效

1. 在“智能体身份”点击“模拟吊销”。
2. 返回农场点击“运行一次”。
3. 展示最新的 REVOKED 拦截记录。

结束语：“Demo 串起了主人实名 DID、智能体 AIC、身份 VC、游戏准入和行为审计。当前用兼容模拟层稳定演示，拿到测试参数后可以平滑切换到中移通证真实接口。”
