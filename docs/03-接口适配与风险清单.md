# 接口适配与风险清单

## 已识别的文档差异

| 项目 | 差异 | 适配策略 |
| --- | --- | --- |
| agentType | create 接口 `1=个人`，issue 接口 `0=个人` | 在端点内部映射，不共享外部枚举 |
| vcRecordId | 部分接口为 String，签发接口标为 Integer | 领域模型统一保存为 String |
| 智能体 ID | 授权接口出现 `acid`，其他位置使用 AIC | 领域模型只使用 `aic`，原字段限适配层 |
| 密钥命名 | 同时出现 appKey、clientSecret、app_key | 配置分开保存，按端点选择签名密钥 |
| 手机号加密 | create 通用说明使用原始 appKey，issue 明确 AES/ECB/PKCS5Padding + MD5(appKey) | create 使用原始 appKey，issue 使用 MD5(appKey)，禁止全局套用 |
| 时间戳 | 通用说明不够明确，部分接口要求 UTC 毫秒且允许正负 180 秒 | 统一生成 UTC 毫秒，联调时校准服务器时间 |
| nonce | 部分接口要求 30 分钟内不可重复 | 使用安全随机数并在业务侧记录短期去重 |

## 安全要求

- 所有中移密钥只存在后端环境变量中。
- 前端、数据库和日志不得保存完整手机号或私钥。
- HMAC 使用排序后的紧凑 JSON，输出大写十六进制。
- 回调必须验签，并以请求 ID 或凭证记录 ID 做幂等处理。
- 日志仅记录追踪号、状态和脱敏标识。
- 真实环境禁止开放 Demo 的凭证状态模拟接口。

## 当前边界

真实适配器已具备请求签名、手机号端点加密、创建、签发和状态查询骨架。由于尚无测试参数，默认 `CREDENTIAL_PROVIDER=mock`，不会向任何外部平台发送请求。
